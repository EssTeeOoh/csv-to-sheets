Privacy Policy

CSV to Google Sheets lets a user upload a CSV file and create a Google Spreadsheet from that file. This policy explains what data the app accesses and how that data is used.

Information the app accesses

  • Google account authorization needed to create and update Google Sheets files.
  • CSV files that the user uploads to the app.
  • Basic technical logs needed to operate and troubleshoot the service.

How the app uses Google user data

The app uses Google Sheets and Google Drive access only to create a spreadsheet requested by the user, write uploaded CSV data into that spreadsheet, and adjust sharing settings when the user requests a public sheet link.

How uploaded data is handled

Uploaded CSV files are processed to validate structure, create the target spreadsheet, and upload the data. Temporary processing files and job status files are retained only as long as needed for operation and cleanup.

Data sharing

The app does not sell user data. Data is shared only with Google services that are required to create and update the spreadsheet requested by the user.

Security

The app uses OAuth credentials and access tokens to communicate with Google APIs. Reasonable steps are taken to limit access to credentials, temporary files, and operational logs.

User choices

A user can stop using the app at any time and can revoke the app's access from their Google account permissions page.

Contact

For questions about this policy, contact the app owner using the support email listed on the Google OAuth consent screen.
